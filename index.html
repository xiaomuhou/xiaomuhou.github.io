Motive使用技巧记录

发表于 2025-04-19 | 分类于 note
字数统计: 543

Optitrack使用记录

1.Markset设置，手动或者自动标签

必须需要先手动记录一段数据task才能记录，然后切换到edit界面，toolbar栏中点击markerset pane，然后进行分配，

2.背景问题

toolbar位置无法实现grad off/on,新发现一个方法，在edit-application setting-grid color，设置成黑色即可消除背景。

3.maker点不出现

反光点只有单个摄像头看到（未被三角化）

Perspective 只显示 至少被 2 台摄像头同时识别到的点
→ 只在一个摄像头里看到 = 仍是 2D 点 = 不算 Marker

  • 打开 View → Cameras → Rays
  • 看是否有两条以上射线交汇到该点
  • 若只有一条射线 → 再调整一下摄像头角度或遮挡

识别参数过低或过高

摄像机能看到，但系统没把它当“可用 marker”

  • 减小 / 增大 Threshold**（阈值）**
  • 关闭 Marker Size Filter**（尺寸过滤）**
  • 开启 Auto Identify

没有 Labeling / 还未进入 3D Reconstruction

Perspective 显示的是 已重建 + 已识别的标记点

  • 是否开启 Reconstruction
  • 是否选择 3D Mode**（不是 2D Mode**）
  • 是否误开了 Hide Unlabeled Markers

路径：

View → Perspective → Show Unlabeled Markers

系统未校准好（Calibration 不足）

如果校准漂了
→ 三角化失败 → 无 3D Marker

  • 重新 Wand 校准
  • 查看 Solve Errors 是否过大

4.标记问题流程

关于label标签，建立markerset，点击view，调出markerset pane，在平面内增加label，然后自动分配，进行采集。

数据处理

5.图片处理

DATA EDITING

Label选择点，可以看到轨迹，在perspective view 窗口选择标记点，观察轨迹曲线

曲线操作：

\1. Timeline，鼠标右键，左右拖动自有放大缩小

\2. Autoscale graph 右键上下调整垂直缩小

\3. 中键拖动调整显示轨迹曲线范围，不更改时间轴当前选择范围

\4. 在时间线左键拖动，选定时间线范围，数据处理

\5. 按F，缩放到选定的范围，SHIFT F 绘制完整的时间轴

Edit tools

Trim tails， fill gap， smooth， swap fix

修减数据；插值填补缺失数据；平滑处理曲线

相机开启预热1小时—-非常重要
