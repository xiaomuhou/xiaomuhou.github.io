Fluent记录

简要记录下，复杂流程还是建模里面直接处理完成比较好

sw比较熟悉，不再赘述；

若为creo，在装配体中直接布尔运算即可，直接在模型中建立流场不不再进入spaceclaim，对应一下傻瓜操作，则直接进入第四阶段；

以下为傻瓜式记录操作，方便使用。

第一阶段：将 .prt 导出为通用格式（在建模软件中操作）

ANSYS 直接读取原生 .prt 有时会因接口未配置而报错，转成 .stp 最稳妥。

  1. 在 Creo（或 UG NX）中打开你的飞行器 .prt 文件。
  2. 点击左上角 文件 (File) → 另存为 (Save As) → 保存副本 (Save a Copy)。
  3. 在弹出的窗口底部，点击 类型 (Type) 下拉菜单，选择 STEP (\*.stp)（或者选择 Parasolid (\*.x_t)）。
  4. 文件名改成纯英文或数字（例如 aircraft.stp，路径和文件名尽量不要有中文），点击 确定 (OK)，在随后弹出的导出选项框里直接点 确定 (OK)。

第二阶段：建立 Workbench 流体工程

  1. 打开桌面的 Workbench（图标是一个蓝黄色的齿轮/箭头）。
  2. 看界面最左侧的 Toolbox（工具箱） 列表，找到 Analysis Systems（分析系统） 并点击它左边的 + 号展开。
  3. 在列表里找到 Fluid Flow (Fluent)，鼠标左键按住它不放，直接拖到右边空白的 Project Schematic（工程视图区），松开鼠标，会出现一个包含 A1 到 A6 的小方框表格。
  4. 在这个表格的第 2 行 A2: Geometry 上点击 鼠标右键 → 鼠标移到 Import Geometry（导入几何体） → 点击 Browse...（浏览）。
  5. 在弹出的文件夹窗口中，找到刚才导出的 aircraft.stp，选中后点击 打开 (Open)。此时 Geometry 右侧会变成一个绿色的对勾。

第三阶段：建风洞并“挖掉”飞机（在 SpaceClaim 中操作）

  1. 在 A2: Geometry 上点击 鼠标右键 → 点击 Edit Geometry in SpaceClaim...（耐心等待 10 到 30 秒，软件会弹出一个全新的三维窗口 SpaceClaim）。
    • 视角操作口诀：按住鼠标中键（滚轮）拖动是旋转模型；按住 Ctrl + 鼠标中键拖动是平移模型；滚动滚轮是缩放。
  2. 创建外流场空气盒：
    • 看界面最顶部的菜单栏，点击 准备 (Prepare) 选项卡（如果是英文版则点 Prepare）。
    • 在左上角找到 外壳 (Enclosure) 按钮（图标是一个小圆柱外面套着一个透明正方体），左键点击它。
    • 用 鼠标左键点击一下屏幕中心的飞行器模型（选中后飞行器外面会立刻出现一个半透明的紫色/绿色方框）。
  3. 修改风洞方框的尺寸：
    • 看屏幕左侧中间的 选项 - 外壳 (Options - Enclosure) 面板。
    • 找到 对称尺寸 (Symmetric dimensions) 这一项，把前面的勾去掉（因为飞机尾部需要留更长的空间算尾流）。
    • 此时屏幕上会出现 6 个带箭头的尺寸输入框（或者直接在左侧面板的 6 个方向框里输入数字）。假设你的飞机总长大约是 1000 mm（1米），为了第一次算得快，把机头前方、上下、左右这 5 个方向的数字都改成 3000 mm，把机尾正后方的那个数字改成 6000 mm（如果你的飞机是 10 米长，就对应填 30000 mm 和 60000 mm，即机身长度的 3 倍和 6 倍）。
    • 输完数字后，找到模型区左上角的一个 绿色对勾图标（完成 / Complete），左键点击它（或者直接按键盘上的 Enter 回车键）。
    • 再按一下键盘左上角的 Esc 键退出外壳工具。此时软件已经自动在方盒内部挖出了一个飞机形状的空腔。
  4. 屏蔽原来的实体飞机（极其关键，漏掉必报错）：
    • 看屏幕最左侧上方的 结构 (Structure) 树状列表。
    • 你会看到列表里有两个东西：一个是你原来的飞行器名字（比如 aircraft），另一个是 Enclosure（外壳）。
    • 在原来的飞行器名字（aircraft）上点击 鼠标右键 → 在弹出的菜单最上方点击 抑制物理场 (Suppress for Physics)。
    • 此时 aircraft 前面的图标上会多出一个红色的禁止小标志（或者蓝色的屏蔽符号），并且可以把 aircraft 前面的复选框勾掉隐藏它。
  5. 直接点击 SpaceClaim 窗口右上角的 X 关闭窗口（无需手动点保存，Workbench 会自动同步保存）。

备用说明：如果你的 Workbench 没有 SpaceClaim，而是打开了 DesignModeler (DM)

  1. 进 DM 后先点左上角的 Generate（闪电图标） 显示出飞机。
  2. 点击顶部菜单 Tools → Enclosure → 在左下角 Details 框里把 Cushion 改成 Non-Uniform，填好上下左右前后的距离 → 点击顶部 Generate（闪电图标）。
  3. 点击顶部菜单 Create → Boolean（布尔运算） → 在左下角 Details 框里把 Operation 改为 Subtract（减去） → 点击 Target Bodies 右侧的 Not Selected，在屏幕上点一下大空气盒子，点 Apply → 点击 Tool Bodies 右侧的 Not Selected，在左侧树里点一下原来的飞机实体，点 Apply → 确保 Preserve Tool Bodies 是 No → 点击顶部 Generate（闪电图标），关掉窗口即可。

第四阶段：给边界命名并画网格（在 Mesh 中操作）

  1. 回到 Workbench 主界面，用鼠标左键 双击第 3 行 A3: Mesh（等待弹出 Meshing 窗口）。
  2. 认识选面工具与隐藏快捷键（必用）：
    • 看顶部工具栏中间，有一个绿色小正方体，其中一个面涂成深绿色的图标，叫做 Face（面选择工具），左键点击它（或者直接按键盘快捷键 Ctrl + F）。只有处于这个模式下，鼠标才能单选某一个面。
  3. 给外风洞的 6 个大面命名：
    • 第一步（看清机头朝向）：转动视角，透过半透明盒子看清里面的飞机机头朝向哪一面。
    • 命名入口 (inlet)：用鼠标左键点击机头正前方的那个大外表面（选中后会变成绿色）→ 按一下键盘上的字母 N 键 → 在弹出的小框里输入 inlet → 点击 OK。
    • 命名出口 (outlet)：转动视角到飞机屁股后面，用鼠标左键点击机尾正后方的那个大外表面 → 按键盘 N 键 → 输入 outlet → 点击 OK。
    • 命名四周远场 (symmetry)：按住键盘上的 Ctrl 键不放，用鼠标左键依次点击盒子剩下的 上、下、左、右 4 个外侧面（此时 4 个面同时变绿）→ 松开 Ctrl，按键盘 N 键 → 输入 symmetry → 点击 OK。
  4. 隐藏外面盒子，给里面的飞机表面命名：
    • 按住 Ctrl 键，把外面盒子的 6 个大面全部点绿选中 → 在模型上点击 鼠标右键 → 点击 Hide Faces（隐藏面）（或者直接按键盘 F8）。
    • 此时外面的大盒子消失了，屏幕正中央只剩下里面的飞行器表面！
    • 在空白处按住 鼠标左键拖出一个大框，把整个飞行器的所有表面全部框选住（飞机会全部变成绿色）→ 按键盘 N 键 → 输入 aircraft_wall → 点击 OK。
    • 在屏幕空白处点击 鼠标右键 → 点击 Show All Faces（显示所有面），把外面的盒子重新显示出来。
    • 检查一下：展开左侧树最下方的 Named Selections，确保里面有 inlet、outlet、symmetry、aircraft_wall 这 4 项。
  5. 设置飞机表面网格加密（防止飞机表面太粗糙）：
    • 在左侧树的 Mesh 字样上点击 鼠标右键 → 鼠标移到 Insert（插入） → 点击 Sizing（尺寸调整）。
    • 看屏幕左下角的 Details of "Face Sizing" 属性框：
      • 找到 Scoping Method，点击它右侧的 Geometry Selection，在下拉菜单里改成 Named Selection。
      • 在下一行 Named Selection 右侧点击黄色空白框，下拉选择 aircraft_wall。
      • 找到下方的 Element Size（单元尺寸），点击右侧的 Default，输入一个具体数值：如果你的飞机长 1 米左右，这里输入 0.015 m（或者 15 mm，看它后面默认跟的单位是 m 还是 mm）；如果飞机长 10 米，这里就填 0.15 m（150 mm）。
      • 找到下方的 Behavior 或观察整体设置，无需改其他项。
  6. 生成网格并查看数量：
    • 点击顶部工具栏最显眼的 Generate（生成，带黄色闪电的图标） 按钮，等待底部绿色进度条走完（通常需要几十秒到两分钟）。
    • 点击左侧树的 Mesh，即可看到带网格线的模型。看左下角属性框，展开最底部的 Statistics（统计），看一下 Elements（网格总数）是不是在 30 万 到 200 万 之间（这个数量算得又快又准）。
  7. 关闭并更新（极其重要）：
    • 直接点击 Mesh 窗口右上角的 X 关闭它。
    • 回到 Workbench 主界面，此时你会看到 A3: Mesh 右边是一个黄色的闪电符号。
    • 在 A3: Mesh 上点击 鼠标右键 → 点击 Update（更新）！耐心等几秒钟，直到黄色闪电变成 绿色对勾，才能进下一步。

第五阶段：设置 Fluent 并开始计算（在 Fluent 中操作）

  1. 在 Workbench 主界面，鼠标左键 双击第 4 行 A4: Setup，弹出一个叫 Fluent Launcher 的小窗口：
    • 在左侧勾选 Double Precision（双精度）。
    • 在下方找到 Solver Processes（求解器核数），把默认的 1 改成 4 或 8（根据你电脑 CPU 核心数填，算得快好几倍）。
    • 点击底部的 Start 按钮，进入 Fluent 主界面。
  2. 第一件事：检查飞机尺寸单位对不对（新手防呆必查）：
    • 看左侧树 Setup → 点击 General。
    • 在紧挨着它的中间面板里，点击 Scale...（缩放） 按钮。
    • 看弹出的小框里的 Domain Extents（计算域范围），看 Xmax - Xmin 是几米。如果显示几米或几十米，说明单位完全正确，直接点 Close 关掉；如果显示几千米（比如把毫米当成米导入了），就把下面的 Mesh Was Created In 选成 mm，点一下 Scale 按钮，再点 Close。
  3. 第二件事：看清风吹向哪个坐标轴，设置飞行速度：
    • 先看一眼右侧图形窗口里的飞机和右下角的 红绿蓝 XYZ 坐标轴。如果看不清里面的飞机，可以在顶部菜单点 View → 把外面的框隐藏，或者直接回忆你在 SpaceClaim 里机头朝哪个轴。
    • 更简单的确认方法： 看左侧树展开 Boundary Conditions（边界条件） → 展开 Inlet → 用鼠标左键 双击 inlet。
    • 在弹出的窗口中，找到 Velocity Specification Method（速度指定方法），点击右侧下拉菜单，把默认的 Magnitude, Normal to Boundary（垂直于边界向内吹） 保持不变！
    • 重点技巧： 只要你的 inlet 是刚才在机头正前方选的那个平面，保持默认的 Magnitude, Normal to Boundary，Fluent 就会自动垂直于入口平面、朝着盒子内部（也就是从机头往机尾）吹风，你根本不用管是 X 轴还是 Z 轴！
    • 直接在下一行 Velocity Magnitude [m/s] 输入你的飞行速度，比如输入 50（代表 50 米/秒，即 180 公里/小时）。
    • 点击底部的 Apply，再点击 Close。
  4. 第三件事：设置阻力监控曲线（看它什么时候算完）：
    • 看左侧树下半部分的 Solution（求解） → 展开 Report Definitions（报告定义） → 在 Report Definitions 上点击 鼠标右键 → New（新建） → 鼠标移到 Force Report（力报告） → 点击 Drag...（阻力）。
    • 在弹出的窗口中：
      • Name 保持 drag-rfile 或改成 drag。
      • 在右侧的 Wall Zones（壁面区域） 列表里，用鼠标左键点选 aircraft_wall（必须点成深色选中状态！）。
      • 在左下角的 Force Vector（力方向向量） 里，看你的气流是从哪个轴吹过来的（比如气流沿 +X 方向吹，就填 X=1, Y=0, Z=0；如果沿 -Z 吹，就填 X=0, Y=0, Z=-1）。
      • 在窗口底部，把 Report File 和 Report Plot（画阻力曲线图） 都打上勾。
      • 点击 OK。
  5. 第四件事：初始化并开始计算：
    • 在左侧树 Solution 下，鼠标左键 双击 Initialization（初始化） → 在中间面板保持默认的 Hybrid Initialization → 直接点击下方的 Initialize 按钮（等 3 秒钟，底部控制台文字停住即可）。
    • 在左侧树 Solution 下，鼠标左键 双击 Run Calculation（运行计算） → 在中间面板找到 Number of Iterations（迭代步数），输入 150 → 点击底部的 Calculate（计算） 按钮！
    • 如果弹出一个小提示框，直接点 OK。此时屏幕中间会自动跳出残差曲线图和阻力变化曲线图，电脑开始全力计算。等 150 步跑完（或者阻力曲线完全变成一条水平直线），弹出 Calculation complete 点击 OK。
    • 直接点击 Fluent 右上角的 X 关闭窗口（会自动保存结果）。

第六阶段：导出漂亮的压力云图与三维流线（在 Results 中操作）

  1. 回到 Workbench 主界面，鼠标左键 双击最后一行 A6: Results，打开后处理软件 CFD-Post。
  2. 第一步：画出飞行器表面压力云图（红蓝彩色机身）：
    • 看顶部工具栏中间偏左，找到一个画着彩色渐变圆圈/等高线的图标，鼠标放上去会显示 Contour（云图），左键点击它 → 在弹出的名字小框里直接点 OK。
    • 看屏幕左下角的 Details of Contour 1 属性框：
      • 找到 Locations（位置），点击右侧框，下拉选择 aircraft_wall。
      • 找到 Variable（变量），确认右侧是 Pressure（压力）。
      • 找到 Range（范围），可以把默认的 Global 改成 Local（局部范围，色彩对比最鲜明）。
      • 点击属性框底部的 Apply 按钮！
    • 此时屏幕中央立刻出现彩色的飞行器表面压力分布：机头和机翼前缘是深红色（高压驻点区），机翼上方是深蓝色（低压吸力区）。
  3. 第二步：画出绕过飞机的三维彩色流线：
    • 点击顶部工具栏中画着几条弯曲彩色线条的图标 Streamline（流线） → 在弹出的小框直接点 OK。
    • 看屏幕左下角的 Details of Streamline 1 属性框：
      • 找到 Start From（起始位置），点击右侧下拉框，选择 inlet（如果觉得从整个大入口出发的线太分散，也可以选 aircraft_wall，再把下面的 Direction 改成 Forward and Backward，这样画出来的流线全都是紧贴着机身绕流的！）。
      • 找到 # of Points（流线根数），把默认的 25 改成 100。
      • 点击底部的 Apply 按钮，屏幕里就会长出 100 根绕过飞行器的彩色三维速度流线。
  4. 第三步：播放气流流动动画与保存高清白底图片：
    • 看动画：点击顶部工具栏中像电影胶片播放键的图标 Animation（动画） → 选中列表里的 Streamline 1 → 点击面板里的 三角形播放键 (Play)，就能看到空气小球顺着机翼飞过的动态效果（点 Stop 停止并关闭动画框）。
    • 保存高清图：在右侧模型背景空白处点击 鼠标右键 → Viewer Options（或者点顶部相机图标旁边的设置），可以把背景改成纯白色；调好最好看的视角后，点击顶部工具栏的 照相机图标 (Save Picture) → 勾选 White Background → 点击 Save 即可导出高清结果图。
